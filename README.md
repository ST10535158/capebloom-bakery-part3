## Project overview
Cape Bloom Bakery is a responsive five-page academic website demonstrating HTML, CSS and JavaScript skills. Part 3 adds interactive functionality, forms, validation, SEO, dynamic product filtering, a gallery lightbox, an OpenStreetMap embed and GitHub Pages deployment.

## Live website
**GitHub Pages:** https://st10535158.github.io/capebloom-bakery-part3/

**Repository:** https://github.com/ST10535158/capebloom-bakery-part3

## Pages
- `index.html` — Home
- `about.html` — About
- `products.html` — Products, search/filter and gallery
- `enquiry.html` — Enquiry form with client-side validation and response
- `contact.html` — Contact form, validation and interactive map

## Part 3 features
- Responsive navigation for desktop and mobile
- Dynamic product search and category filtering
- Gallery lightbox interaction
- Contact and enquiry form controls and validation
- SEO title tags, meta descriptions, keywords, semantic headings and accessible image/artwork alternatives
- `robots.txt` and `sitemap.xml`
- OpenStreetMap interactive map
- GitHub Actions workflow for GitHub Pages
- Changelog and evidence documentation
